# Test Plan: REQ-013 - Idempotent, retry-safe Workspace mutations

## Testing Objectives

**Requirement:** Idempotent, retry-safe Workspace mutations
**Category:** non-functional
**Description:** Because Cloud Tasks delivers at least once and Workspace calls can time out after the change has landed, every Workspace mutation must be safe to replay. Each step carries a stable idempotency key derived from (requestId, stepId, attempt-invariant payload hash). Before mutating, the executor reads the live Workspace state and short-circuits when the intended state already holds. Directory API errors are classified into retryable (429, 5xx, quota exhaustion — retried with exponential backoff and jitter, honoring Retry-After) and terminal (400, 403, 404 for a missing prerequisite — failing the step immediately without burning the retry budget). The Workspace client is the single choke point for this policy; no phase implements its own retry logic.

## Acceptance Criteria

Criterion text lives HERE once; every section below cites the AC id.

- **AC-REQ-013-1** [automated] [VERIFIED] Replaying any step of any phase against a Workspace state where the intended change already holds produces no additional mutation and resolves the step as satisfied
- **AC-REQ-013-2** [automated] [VERIFIED] Each step's idempotency key is stable across attempts and distinct across requests and steps
- **AC-REQ-013-3** [automated] [VERIFIED] A 429 or 5xx from the Directory API is retried with exponential backoff and jitter, honoring Retry-After when present
- **AC-REQ-013-4** [automated] [VERIFIED] A 400 or 403 fails the step immediately and does not consume further retry attempts
- **AC-REQ-013-5** [automated] [VERIFIED] A mutation that times out client-side but succeeded server-side is detected by the pre-mutation state read on the next attempt and not applied twice
- **AC-REQ-013-6** [automated] [VERIFIED] All retry and classification behavior lives in the shared Workspace client, verified by the absence of retry logic in any phase handler
- **AC-REQ-013-7** [automated] [PENDING] Concurrent duplicate task deliveries for the same step result in exactly one Workspace mutation
